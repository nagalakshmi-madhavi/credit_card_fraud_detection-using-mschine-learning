#XGBoost‑Driven Credit Card Fraud Detection and Risk Assessment

A Machine Learning-based Credit Card Fraud Detection system that analyzes transaction details and uses XGBoost classification to identify fraudulent and legitimate transactions. The project includes EDA, data preprocessing, feature engineering, SMOTE for class imbalance, model evaluation, hyperparameter tuning, and Streamlit deployment.


# Credit Card Fraud Detection Using Machine Learning

**Developed by:** Nagalakshmi Madhavi Chimakurthi

## Project Overview
This project uses machine learning techniques to detect fraudulent credit card transactions and classify transactions as legitimate or fraudulent.
